# Theory of Person (redirects)

Theory of a person lives in Persons. This app stays deployed at
`context.lacollecteur.com` so old bookmarks still resolve.

| Old path | New path |
| --- | --- |
| `/` | `/persons` |
| `/person/:id` | `/persons/:id/theory` |
| `/notes` | `/persons/notes` |
| `/login` | Persons login |

Do not add product UI or APIs here.
