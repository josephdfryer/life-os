# Life OS Companion

Open `LifeOSCompanion.xcodeproj` in Xcode 16+. The project contains macOS, embedded login-item, and iOS targets plus a local Swift package. See `docs/COMPANION_ARCHITECTURE.md` and `docs/runbooks/COMPANION_RELEASE.md` before changing privacy boundaries or shipping.

No target needs the monorepo, Node, Homebrew, Python, local environment files, or LaunchAgent installation at runtime.
