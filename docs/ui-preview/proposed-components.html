What this page shows

A visual preview of adopting shadcn/ui + Radix primitives themed to your existing Warm Concrete design system. Today inline styles

~1,500 inline style={{}} blocks across apps. Headers duplicated 4×. Modals built from scratch. No shared Dialog, Dropdown, or Table.

Proposed shadcn + tokens

Components live in packages/ui, copy-paste owned by you. Radix handles focus traps, keyboard nav, ARIA. Tailwind utilities replace most inline styles.

Section 05

Recommended libraries

All free / open-source. Tier 1 is the foundation; Tier 2 fills specific gaps as you need them.

shadcn/ui

★ 118k · MIT · copy-paste

Foundation for Dialog, Dropdown, Table, Tabs, Select, Calendar. Tailwind v4 supported. Lives in your repo.

Tier 1 — adopt first

Radix UI

★ 18k · MIT · headless

Accessibility layer under shadcn. Focus traps, keyboard nav, ARIA. Use when you need behavior without default styling.

Tier 1 — adopt first

Lucide React

★ 12k · ISC · icons

1,600+ tree-shakeable icons. Replaces ad-hoc SVGs and text arrows across Headers and forms.

Tier 1 — adopt first

Dice UI

★ 2k · 242 components

shadcn-compatible: data tables, comboboxes, date pickers. Great for CRM filters and birthday fields.

Tier 2 — as needed

TanStack Table

★ 26k · headless

Sorting, filtering, pagination for People list, Inbox, Admin. Pair with shadcn Table styling.

Tier 2 — as needed

cmdk

★ 9k · command palette

⌘K search across people, places, apps. Natural fit for Life OS cross-app navigation.

Tier 2 — as needed

Sonner

★ 10k · toasts

Toast notifications with stacking and theming. Replaces hand-rolled Toast in @life-os/ui.

Tier 2 — as needed

Better Upload

★ 1.3k · file upload

Drop zones for vCard, CSV, Google Timeline import flows in Persons and Places.

Tier 2 — as needed
Section 06

Recommendation

Keep Warm Concrete. Add shadcn for complex primitives.

You already have a distinctive design system in @life-os/ui — the gap isn't aesthetics, it's interactive components (dialogs, dropdowns, tables, date pickers) rebuilt from scratch in every app. Initialize shadcn in packages/ui, map its CSS variables to your existing tokens, and migrate the highest-duplication patterns first: Header → AppShell, modals → Dialog, People/Inbox → DataTable.

Estimated Phase 1 setup: one session. No visual breaking changes if tokens are mapped correctly.
